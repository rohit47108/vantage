# General native extraction and six-detector validation

This is an implemented scientific backend increment toward the complete source-spectrum workflow. It accepts source coordinates and optional angular motion, arbitrary native observation records, and PSF/aperture geometry. The currently approved release is DR1 processing version 7.0.5 across all six detectors. The public source interface still exposes the earlier retained D2 workflow until the general field/job/interface layer is integrated. This increment does not complete requirement F.

## Verified input associations

The current [official IRSA source-discovery notebook](https://caltech-ipac.github.io/irsa-tutorials/spherex-source-discovery-tool-demo/) explicitly selects DR1 `solid_angle_pixel_map/cal-sapm-v3-2026-191` for detectors 1–6. The [product documentation](https://caltech-ipac.github.io/spherex-archive-documentation/spherex-data-products/) describes these maps in square arcseconds. All six actual maps were downloaded and inspected. No constant 6.15-arcsecond pixel-area fallback is used.

For each detector, an actual native reference exposure and an actual DataLink response establish its spectral-calibration file association. The native IMAGE HISTORY provides spectral-WCS, SIP and ePSF calibration UUIDs. These exact IDs, processing version, detector, sky-coordinate orientation and input checksums are pinned in `config/scientific_calibrations.json`. The adapter snapshots this registry per extraction; an unsupported release, processing version, changed UUID or wrong orientation is rejected, rather than selecting the newest available calibration.

Reference responses, source/calibration files and their hashes are retained in `acquisition.json` and `datalink_d*.xml`. Large calibration files use lossless gzip of the original FITS byte stream. The compressed checksum and original decompressed FITS checksum are both checked. No floating-point quantization, cropping or header rewrite is used for these maps. The original D2 map files remain referenced in the previous photometry package to avoid duplicate retention.

IRSA calibration downloads sometimes returned HTTP 502/503 during this work. `backend/archive.py` now preserves the actual DataLink association and can fetch that same release/file from the [official NASA S3 mirror](https://caltech-ipac.github.io/spherex-archive-documentation/spherex-data-access/). The mirror allowlist accepts only the documented DR1/QR3 spectral-WCS and solid-angle calibration paths; it does not become a generic S3 fetch proxy. Sky discovery also retries transient connection/HTTP failures and can query the documented deep collections and SIA TIME bounds. Overflow remains explicit. Metadata discovery alone is not a usable-source or full-coverage guarantee.

The current official extraction implementation was inspected recursively, including [aperture_photometry.py](https://github.com/Caltech-IPAC/irsa-tutorials/blob/6615d7b7bb43af252dee798a538c87d175436d9c/tutorials/spherex/spherex_source_discovery/spherex_source_discovery_tool/aperture_photometry.py). That exploratory utility permits a constant-area fallback and simple aperture/background statistics. Vantage retains its separate tested calibrated-area, ePSF, background/centroid covariance and quality-gate implementation; an illustrative tutorial is not treated as validation of every scientific use.

## Implemented numerical/data path

`backend/native_extraction.py` defines validated source-position and extraction-option contracts. A fixed ICRS coordinate requests that same sky position at all dates. Supplied angular motion uses `pmra = mu_alpha*cos(dec)` and a TCB Julian reference epoch, transported to each UTC acquisition using the existing tested angular model. Observer parallax and perspective acceleration are not supplied or silently inferred.

The extractor processes one to 512 distinct physical observations, checks cancellation between inputs, validates native observation/detector/time identities and approved calibration IDs, and keeps calibration handles local to one job. It measures native pixels only. The calibrated SAPM area at the source must agree with the spherical native WCS pixel area within the predeclared 0.1% bound. Position-dependent ePSF rendering, source/background fits and statistical covariance follow the separately validated kernel in `backend/photometry.py` and the prior [photometry methods](../photometry/METHODS.md).

Automatic centroid refinement is attempted only when the initial fixed-position PSF signal-to-noise is at least 20. Fainter forced measurements retain their supplied position and conditional errors. A failed attempted refinement is not silently replaced by a passing fixed fit. This S/N threshold selects the supported numerical position-fit regime; it is not a discovery-confidence threshold.

Results retain per-sample observation ID, detector, acquisition time, native cutout/derived-section geometry, input hash, calibrated wavelength/bandwidth, signed flux, statistical error, flags, background and position diagnostics, and explicit accepted/diagnostic/rejected states. Physical observations are distinguished by observation **and detector**; an observation ID alone can repeat across detectors. Native brightness/residual stamps are stored separately with hashes, rather than forcing every image into a large initial JSON response. CSV/ECSV/SVG/provenance publication is atomic at the manifest boundary. Failed coverage does not become a zero-flux sample.

## Independent reference and declared checks

`python -m scripts.validate_native_extraction` runs both methods on seven actual retained inputs: one reference on each detector, plus the previously validated D2 observation. The first D2 footprint hit is an authentic negative case outside the native cutout. D6 contains a defective aperture pixel; its PSF fit can use the remaining calibrated support, while the aperture measurement is rejected.

The declared bounds remain 10% relative to the CALSPEC central-band top-hat approximation, 5% aperture/PSF agreement for passing pairs, 0.1% WCS/SAPM pixel-area agreement, and normalized residual score below 3. The retained results provide successful PSF measurements on all six detectors, successful aperture measurements on detectors 1–5, eleven passing measurements total and five passing method pairs. Wavelengths span approximately 0.91–4.77 microns. No gate was relaxed to obtain those results.

P330E is also an SPHEREx calibrator. This comparison tests reduction consistency and the implemented flux convention, not an independent absolute mission gain scale. Central CWAVE/CBAND top-hat synthesis does not integrate the full position-dependent wavelength response. Statistical errors exclude unprovided native correlations, calibration/PSF systematics and fixed-position uncertainty. The original Monte Carlo and analytic kernel tests remain necessary evidence; six real points alone do not prove those uncertainty assumptions generally.

## Still required

General live source selection, immutable discovery fields and persistent jobs, accessible browser controls, time/quality filtering, per-sample lazy image inspection and public acceptance must be integrated. QR3 and future calibration bindings need their own reference/canary checks. Full missing-channel accounting, scientifically defined bins/limits, wider isolation/crowding and variable-source behavior remain pending. The full project still requires subtraction, remaining coadd methods, release operations, investigations/embed and durable hosting; this backend increment does not change those requirements.
