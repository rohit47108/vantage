# Time comparison, intervals and day groups

November 15, 2026. This document describes visual navigation over actual retained individual exposures. Numerical subtraction, PSF matching, absolute registration and moving-object stacking remain separate, unfinished workflows. The original source FITS identities, checksums, calibration links and interpretation limits remain in each sequence manifest and exported JSON.

## Implemented behavior

Side-by-side and swipe comparison select two actual exposures by their original sequence indices. Their full acquisition timestamps, observation identities, detector, wavelength, release, source-core bits and original FITS links are exposed separately. The shared camera preserves the same pan and zoom between images. Pixel inspection uses the specific visible exposure, including each image's own world coordinates, brightness, wavelength and quality arrays. The comparison does not compute a difference, flux ratio or detection significance.

In swipe mode both canvases occupy the same square, sized from the available rendered area with ResizeObserver. A CSS inset clipping path exposes frame B to the right of the divider; frame A remains underneath. The [CSS Masking standard](https://www.w3.org/TR/css-masking-1/#clipping-paths) specifies that the clipped-out region does not receive pointer events. Actual M101 browser tests independently verify that clicks on the left and right read acquisitions A and B respectively. Canvas coordinates remain unchanged by the clipping operator. Keyboard users can focus either image and inspect it, and operate the native divider slider. Source-tracked thumbnails retain their distinct sky-center warning; their aligned stamp positions do not establish one fixed sky coordinate.

The default display uses the common prepared normalization and a shared contrast exponent. An explicitly enabled independent mode gives A and B separate display exponents. This changes their rendered contrast, never the underlying physical arrays or scientific masks. The mode and values are labeled, shared and exported. Independent stretches do not authorize visual brightness-change measurements. Reset restores the camera, both exponents and divider; changing targets uses the new target's validated view defaults.

`src/viewState.ts` parses and serializes bounded comparison settings: `compare=side-by-side|swipe`, original `frame_a`/`frame_b`, `independent=0|1`, `stretch_a`/`stretch_b` in 0.3–3 and `divider` in 0–100 percent. Unknown comparison modes remain disabled; one-exposure sequences cannot restore comparison. Existing sequence IDs, frame/camera/layer query fields and old links retain their meaning. New fields describe a view and do not change scientific product identity.

## Playback dates and UTC-day groups

`src/timeSelection.ts` supplies pure selection/grouping functions. Optional `time_start` and `time_end` select **inclusive UTC calendar dates of acquisition midpoints**; `time_day` restricts navigation to one UTC-midpoint day. They do not represent exposure start/end integrations or a continuous coverage guarantee. Calendar dates are validated against actual Gregorian UTC dates; input timestamps are converted to UTC before grouping. A valid day with no observations remains an explicit empty selection. Reversed date bounds return no observations; the form also validates its end date against its start date.

Groups retain all original frame indices and their first/last acquisition midpoints. There is no coaddition, averaging, new group image, fitted epoch or invented instantaneous date. The real prepared Ceres group contains the distinct 2025-07-03 02:15:08.816 and 07:02:56.337 UTC midpoints. Its nearly five-hour span remains visible, and playback displays the individual exposures separately. Spectral compatibility, moving-source and quality restrictions remain attached to the sequence; sharing a day does not make incompatible exposures valid for numerical combination.

Stepping, scrubbing, looping and the date strip navigate the filtered list while preserving original indices for input identity, inspection and sharing. Displayed gaps use the actual MJD midpoint difference between the currently adjacent selected exposures. Comparison choices are restricted to that selection; a pair outside a changed interval is reset to actual available members. With fewer than two members playback/comparison cannot run. Empty selections hide stale images/inspectors and offer a button restoring all retained sequence exposures. Date filtering does not issue a new archive query or claim that a retained sequence inventories all observations in that interval. Source discovery and numerical combination maintain their own explicit input-selection contracts.

## Exports and evidence

Sharing reconstructs the immutable sequence URL with both frame indices, camera, layer opacity, comparison/divider/stretch settings and date/group selection. JSON retains these settings and the exact selected original frame indices. The PNG export composes the two actual canvas buffers either side by side or with the same swipe clipping, then labels both acquisition identities, wavelengths, display choices and scientific limits. It does not export only A under a comparison filename. Browser checks decode the PNG and compare pixels from each visible half with the corresponding rendered source canvas.

Node tests use authentic retained Ceres/WISE timestamps plus controlled boundary cases to verify inclusive selection, noncontiguous original indices, UTC conversion, invalid calendars, missing days, reversed bounds and complete URL round trips. Browser tests use actual M101 and prepared target imagery for both inspectors, export pixels, saved links, mobile geometry, automated WCAG checks, filtered playback, single-exposure controls, empty recovery and the Ceres interval. The prior 83-test scientific/API suite governs unchanged numerical/backend code; fresh CI and full local/public browser release evidence are recorded separately in `tasks/product-evidence.md` and `IMPLEMENTATION_STATUS.md` when completed.

Limits: this validates the described visual manipulation and input identity, not precision astrometry, temporal variability, PSF-homogenized residuals or calibrated flux changes. Retained examples are prepared authentic observations with explicit provenance, not a new live archive query. Public backend permanence is still unresolved.
